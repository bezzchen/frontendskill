# Thornmere — site

Next.js 16 + Tailwind. Placeholder marketing page for a small-batch gin.

Media in `public/`: botanical plates (`public/botanicals`), a studio environment map for
image-based lighting (`public/env`). Licences are recorded in `public/ASSET_LICENSES.md` —
all public domain or CC0.

```bash
npm ci
npm run dev
```
