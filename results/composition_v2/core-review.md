The architect owns implementation/register/sourcing boundaries; technical constraints return a tradeoff rather than silently changing the design. Specialists and reviewer have narrower responsibilities.

Explicit invocation permits relevant implementation checks without reopening discovery; natural scope excludes isolated styling/animation fixes and settled execution. Plan-only scope is retained.
- **Source handling:** Adapter distinguishes actual source reads from hashes/registry paths, checks matching bytes, separates expected and actual revisions, labels scoped adaptation honestly and routes absent/mismatched/uncontainable upstream workflow to builtin fallback. No auto-install/upgrade is implied. Existing competing instructions are acknowledged rather than purportedly erased.
- **Review:** Fresh reviewer receives brief/contract/URL/state/evidence inputs without the builder conversation or self-assessment; source inspection follows operation. Browser absence and self-review remain distinct. Required live flow, responsive, state, keyboard and motion checks precede approval, with defect evidence, preference separation and at most two correction/recheck cycles.
- **Four earned invariants:** All remain visible in the entrypoint, including attribution of continuous work and shared-consumer protection, actual scroll/background verification, bounded catalog fit with offline continuation, and explicit spectacle consideration. Architecture adds detailed lifecycle treatment without requiring a new engine.
- **Packaging and historical preservation:** Runtime references/manifest paths are within the installed directory. Full-folder installation is documented; stable single-file restoration remains documented. Frozen v1.2 bytes match pre-edit HEAD exactly. No research-registry runtime dependency is introduced.
- **Instruction size:** Entrypoint measured 756 whitespace-separated words / 5,628 bytes versus pre-edit 1,064 words / 6,978 bytes. Detailed stages are selectively loaded; no obvious unnecessary framework or repeated approval ceremony was introduced.
